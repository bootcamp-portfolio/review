# Python Review

## 구성
- `01_review.ipynb`: Jupyter Notebook 기반 복습 자료

- `multiProcess.py`: 멀티프로세싱 관련 실습 코드

## 실행
Python 환경을 준비한 뒤 필요한 패키지가 있다면 설치하고, Python 파일 또는 Jupyter Notebook을 실행합니다.

```bash

python multiProcess.py
```
